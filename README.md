# Krene 提示词工作台

照着 `01_总结篇_Krene优秀提示词规律.md`、`02_教程篇_自己怎么写提示词.md` 的数据与规则做的**自助提示词生成器**：
填槽位 → 自动成稿 → 实时体检 → 复制到 krene.com 出图。纯静态、零依赖、不联网也能跑（案例封面在离线时会退回文字）。

在线地址：https://yunanofficial.github.io/promote_generation/

## 六个页面

| 标签 | 作用 |
| --- | --- |
| **生成器** | 选模型（Niji 7 / GPT Image-2 / GPT Image 2.5 / Nano Banana / 即梦 3.1）→ 填模型专属槽位 → 自动拼成提示词。Niji 7 带参数面板（`--stylize`、`--chaos`、`--raw`、`--sref`+`--sw`、`--no`）并自动追加正确后缀。**体检**实时报错：误用 `--ar`、`--styleraw`、质量词堆砌、比例写多次、文字没逐字给出、多格缺一致性、参考图没锁身份、中英粘连等。成品框旁可「存为词条」「历史」。 |
| **模板库** | 8 个可复制骨架（立绘 / 氛围场景 / GPT-2 槽位说明书 / 2.5 规格书 / Banana 编辑 / 即梦逗号链 / 多格一致性 / 海报排版），「载入生成器」后替换 `【】` 即可。 |
| **案例库** | 806 条 Krene 提示词**逐字原文 + 封面图**，可按模型、合集筛选，按推荐/长度/标题排序，搜索标题正文作者；点封面看大图（灯箱），可复制、可「以它为基础」载入生成器。 |
| **速查手册** | Niji 7 参数表、中英词库对照、症状→原因→改法排错表、出图前 20 条自检清单。 |
| **我的库** | 你自己的东西：**词条**（保存当前成品，或手填名字保存；同时出现在「词库 → 我的词条」，可一键插入到光标处，支持改名/删除/搜索）+ **生成历史**（停手 2 秒自动记一条，最多 100 条、同文合并；可载入回生成器并还原槽位、复制、转存成词条）。支持**导出 / 导入 JSON** 备份搬迁。 |
| **说明** | 数据来源与口径，附三份完整报告（DOCX / Markdown）下载。 |

## 部署到 GitHub Pages

仓库根目录必须直接放这些文件（`index.html` 在根目录，Pages 才能当首页）。设置路径：**Settings → Pages → Source = Deploy from a branch → main / (root)**。

### 方案 A：只传 14 个文件（推荐，图片自动走站方原图）

站点启动时会探测 `img/` 目录：**没有就把封面直接热链 krene 官方原图**（`www.krene.com/prompt-page-common/*.webp`，已实测对 github.io 的 Referer 返回 200）。
所以只要在 GitHub 网页上把下面这些文件拖进仓库即可，**不必传 805 张图**：

```
index.html     styles.css     app.js      data.js     favicon.svg
.nojekyll      README.md
reports/  01_总结篇_Krene优秀提示词规律.docx   02_教程篇_自己怎么写提示词.docx   03_案例库_首页推荐100条.docx
          01_总结篇_Krene优秀提示词规律.md     02_教程篇_自己怎么写提示词.md     03_案例库_首页推荐100条.md
```

操作：打开仓库 → **Add file → Upload files** → 把上面文件（`reports` 目录整个拖进去）→ **Commit changes**。提交后等 1 分钟重建，刷新页面就有图了。

### 方案 B：连 `img/` 一起传（更稳，17 MB / 805 张）

- **GitHub Desktop**（推荐）：Clone 仓库 → 把整个文件夹内容拷进去 → Commit → Push。
- **网页上传有坑**：GitHub 网页一次最多 100 个文件，`img/` 要分 9 批拖上去，很累。
- 好处：不依赖 krene 的图片服务器，离线/断链也不怕（本地缺图时仍会自动退回站方原图）。

### 常见问题

- **打开没图**：确认 `data.js`、`app.js`、`styles.css`、`index.html` 四个是同一版（旧版 `data.js` 没有封面字段）；`img/` 与站方原图都拿不到时卡片会显示「封面不可用」，点「原页 ↗」看。
- **图片是懒加载的**：往下滚动才会加载，属正常。
- **改了文件没生效**：Pages 重建有 1 分钟延迟，强刷（Ctrl+F5）一下。
- **`.nojekyll` 传不上去**：不影响本站（没有下划线开头的目录），可以跳过。
- **控制台有一条 `img/xxx.webp 404`**：这是启动时探测「本地有没有 `img/` 目录」的正常现象（没图就自动改用站方原图），不影响显示。
- **我的词条/历史不见了**：它们存在浏览器 localStorage 里，清浏览器数据、换浏览器或用无痕模式都会丢；用「我的库 → 导出 JSON」备份，再「导入 JSON」恢复。

## 交互小抄

- **词库**：先把光标放进要填的槽位，再点词库里的词，会插到光标处；Niji 7 显示英文词，中文模型显示中文词。第一个标签「我的词条」是你自己存的内容。
- **手动编辑**：直接在「成品提示词」框里改会进入手动模式（不再被槽位覆盖），点「从槽位重建」恢复同步。
- **填充示例 / 随机灵感**：一键塞入完整范例，或从词库随机组合出草稿再改。
- **存为词条**：成品框下点「存为词条」会按第一个槽位内容自动命名；想自己取名就到「我的库 → ① 我的词条」填名字再点「保存当前成品」，列表里可随时「改名」。
- **生成历史**：改完槽位或手动编辑后停手 2 秒自动记录（内容相同的自动合并到最新，最多 100 条）。「载入」会把当时的正文连槽位一起还原；也可以直接把某条历史「存为词条」。
- **数据在哪**：词条与历史都存在浏览器 localStorage（键名 `krene.studio.v1`），换浏览器/换电脑不同步，用「我的库 → 导出 JSON / 导入 JSON」搬过去；清浏览器数据会一起清掉，重要内容记得导出备份。

## 数据说明

- 来源：krene.com 公开页面与公开接口（首页推荐位 100 条 + 提示词库去重 806 条 + 8 篇官方教程）。
- **67 条 GPT Image-2 案例在站方原始数据里只存了 `$d1`/`$bf` 这类跨文件引用占位符**，本站标记为「无正文」并给原页链接，没有编造任何内容。
- 参数口径（`--stylize` 200–600 最佳、`--sw` 500–700 最实用、Niji 7 不用 `--ar` 等）全部来自官方教程原文与 166 条 Niji 7 案例的实际用法统计。
- 站点为纯静态页面：无后端、无统计、不上传任何数据；你的词条与生成历史只存在你自己浏览器的 localStorage 里，导出/导入都在本地完成。
