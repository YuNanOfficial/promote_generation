# 提示词写作教程：从一句话到出片

> 配套《01_总结篇》使用。本文只讲**怎么做**：一套七步流程、六个可复制模板、五个改写演示、一张排错表。
> 所有模板都取自 Krene 上真实拿到好图的写法，把 `【】` 里的内容换成你自己的即可。

---

## 0. 先建立三个观念

**观念一：提示词是"施工图"，不是形容词比赛。**
写"画面很唯美、很高级"没有用；写"侧逆光 + 浅景深 + 面部高光 + 冷蓝低饱和"才有用。判断标准很简单：**这句话能不能被画出来？** 不能，就换成能画的。

**观念二：模型分两类，语言习惯完全不同。**

| 类型 | 模型 | 它吃什么 | 它不吃什么 |
| --- | --- | --- | --- |
| 标签/参数型 | Niji 7 | 逗号或空格分隔的短标签 + `--参数` | 分点清单、长段落、参考图（它不用参考图） |
| 指令/规格型 | GPT Image-2、GPT Image 2.5、Banana、即梦 | 结构化句子、分点规格、逐字文字 | 纯标签流、`--参数`（除 Banana 的少数开关） |

用一个模型的习惯去写另一个模型，是最常见的翻车原因。

**观念三：一次只改一处。**
出图不对时不要整段重写。每次只动一个槽位（先把主体改对，再改光线，再改构图），不然你永远不知道是哪句话在起作用。

---

## 1. 通用万能公式（先记这一个）

站方给出的基础公式，也是 806 条数据里覆盖率最高的骨架：

> **主体 + 动作 + 环境 + 艺术风格 + 光影 + 构图 + 限制条件**

实际写的时候，把它扩成七个格（缺哪个补哪个，不要空着）：

| 格 | 要写什么 | 例子（可从词库挑） |
| --- | --- | --- |
| ① 交付物 | 用途 + 比例 | `竖版海报 9:16`、`4:5 社媒图`、`正方形头像` |
| ② 主体 | 谁/什么 + 身份 + 外貌 | `银白色短波波头的女高中生，大蓝眼睛，白皙透红肌肤` |
| ③ 动作 | 重心 + 肢体 + 视线 + 动静 | `在台阶中途停下脚步，越过肩膀回头望向镜头` |
| ④ 环境 | 地点 + 背景元素 + 景深 | `通往海边小镇的陡峭石阶，两侧樱花树` |
| ⑤ 风格 | 媒介 + 工艺 + 流派 | `赛璐璐平涂 + 柔和渐变，日式动画电影海报级` |
| ⑥ 光与色 | 光源方向 + 阴影 + 色调饱和度 | `夕阳轮廓光（rim light），柔和粉色与金色调` |
| ⑦ 限制 | 不要什么 + 文字内容 | `严禁额外角色、Logo、水印；标题逐字为"…"` |

**加粗提醒**：⑥ 和 ② 的细节量应该差不多。新手常犯的是主体写了 50 字、光色只有"光线很好"四个字——图面立刻平淡。

## 3. 七步法：从一句话到出片

### 第 1 步：写下一句话意图
`我想画一个在黄昏樱花台阶上回头的女高中生。`
先别管格式——这句话决定的是"主体 + 场景"，其余都是往它上面挂。

### 第 2 步：定交付物（最容易被跳过、却最决定成败）
回答三问：**用在哪**（海报 / 头像 / 设定图 / 社媒 / App 截图）？**什么比例**？**要不要文字或透明底**？
> 依据：806 条里几乎所有海报/截图类案例，都在首句或单独槽位写明了 `9:16`/`4:5`/`2:3`/`16:9`/`1:1`；而失败案例常常整段不提比例。

### 第 3 步：填三个必备槽
①**主体**（身份 + 3–5 个可画的外貌特征）、②**风格**（媒介 + 工艺词）、③**镜头/构图**（景别 + 机位 + 构图法）。
> 数据依据：Niji 7 里主体 68%、风格 67%、镜头构图 51% 是命中率最高的三项；全库 `构图` 出现 244 次、`特写/半身/全身` 合计 233 次。

### 第 4 步：加加分槽（决定"好看"与"专业"）
按性价比排序：**光线 → 色彩 → 材质 → 动作/情绪 → 质量词**。
- 光线写法：`主光源来自画面左侧的硬光 + 阴影边缘柔和 + 逆光轮廓光`
- 色彩写法：`冷蓝 + 低饱和黑白 + 轻微霓虹漫反射`
- 材质写法：`丝滑绸缎面料`、`亮面漆器质感`、`哑光PVC塑胶` ——**材质词比"高清"有用得多**。
- 质量词只留 1–3 个（`细腻`/`8k`/`masterpiece`），写多了纯稀释权重。

### 第 5 步：收口
补齐 ⑦ 限制（不要什么、文字逐字内容）+ 参数（仅 Niji 7）。

### 第 6 步：出图 → 诊断 → 只改一处
对照下面这张表定位问题（详见第 8 节的完整排错表）：
`主体不像` → 加外貌/服装细节；`画面平` → 加光线方向与色彩对比；`没有重点` → 加景别与景深；`太满太乱` → 加留白/简化背景/纯色底。

### 第 7 步：固化
把这次成功的提示词存成模板（把主体、场景、颜色挖成 `【】` 变量），并记下 Niji 7 的 `--sref` 风格码——**同一风格要出十张图时，这是唯一省力的做法**。

## 4. 六个可直接复制的模板

### 模板 A · Niji 7 动漫立绘（标签流）
```
【风格/体裁: official anime key visual / character design sheet / sticker design】,
【主体: 1 girl, 年龄, 发色+发型, 瞳色, 表情】,
【服装: 分件写，注意层级】,
【姿态: standing / dynamic pose / 具体动作】,
full body, 【机位: eye-level / low angle】, centered composition,
white background, 【点缀元素】,
【光线: soft lighting / rim light】,
clean lineart, cel shading, vibrant colors,
--niji 7 --stylize 200 --no text, watermark, blur, bad hands
```
> 要点：① 逗号或空格必须存在，中英相邻尤其要加；② `--stylize` 用 200 起步，别拉满；③ **不要写 `--ar`**。

### 模板 B · Niji 7 氛围场景（英文长句）
```
【风格声明: cinematic anime illustration, painterly】,
【主体 + 一个定格瞬间: A lonely, worn-out black cat plush sitting on top of an old clothing donation box…】,
【物件细节: faded fur, loose seams, dusty fabric】,
【环境: empty residential street, telephone poles, weeds through cracked pavement】,
【光线与情绪: soft evening light, bittersweet nostalgia, subtle depth of field】,
photorealistic textures, Japanese slice-of-life film aesthetic
--niji 7 --raw --stylize 250
```
> 要点：Niji 7 用 `--raw` 会更严格地遵循你的描述；长句里用逗号分层，不要一段到底。

### 模板 C · GPT Image-2 槽位说明书（中文分点）
```
画风总纲：【现代日系二次元写实插画，细腻柔和的清晰线稿，平涂叠加薄涂渐变】
主体：【外貌 4 项 + 服装分件】
动作姿态：重心【】；肢体【】；视线【】；动静感【】
镜头与构图：【景别 + 机位 + 画面平衡 + 留白】
光影色彩：主光源【方向/性质】；阴影边缘【】；色彩【色调 + 饱和度 + 对比】
画幅比例：【9:16】
负面排除：【无文字、无水印、无UI界面、无边框】
```
> 要点：GPT Image-2 有 23% 的优质案例用这种分点体，全库分点案例也是它最多（18 条）。**分点是为了不漏槽位**，不是为了好看。

### 模板 D · GPT Image 2.5 规格书（海报 / 设定图 / 截图）
```
目的：【给谁用、什么场合、要致敬什么】

画布：【比例 + 色调 + 背景构成】

布局：【元素怎么排；主视觉在哪个区位；留白在哪】

主体细节：【逐项特征 + 材质 + 状态】

文本内容：准确使用以下 N 个可见文本元素：
1) 【位置】：“【逐字内容】”
2) 【位置】：“【逐字内容】”

排版：【字体风格 + 字号层级 + 颜色；谁大谁小】

视觉风格：【媒介 + 工艺 + 参考流派 + 配色方案】

限制条件：【只允许出现什么；严禁出现什么】
```
> 要点：**这是唯一能稳定做出"能直接用的成品"的写法**。画面上每个字都要逐字给出，并写清位置和字体风格。

### 模板 E · Banana Pro 编辑指令（锁身份 + 换其余）
```
参考【图1/上传的角色图片】，保持【发型、五官、服装、配饰、配色】完全一致，不要修改角色设计。
把【要改的元素】替换为【新内容】；【画面其余部分如何变化】。
风格：【画风/质感/光线】。
```
> 五大约束动词（站方口径）：**Add / Change / Make / Remove / Replace**。`Replace` 最强，标准句式：`请参考图片1轮子的设计，把图2摩托的后轮替换成图1的轮子`。
> **反向用法**：如果只想要"长相参考"，必须显式解绑——`禁止维持参考图画风，禁止保持参考图角色姿势，参考图只是告诉你角色长什么样，你要完全重新设计`。

### 模板 F · 即梦 3.1 中文逗号链
```
【主体+外貌】，【服装分件】，【动作姿态】，【环境背景】，【光线】，【色彩】，【氛围】，【风格媒介】
```
> 要点：全程逗号，短名词短语，**不要 `--参数`、不要负面词、不要权重括号**（该模型不吃这些）。

### 模板 G · 三视图 / 精灵表 / 表情表（通用）
```
制作一张【4×4】的【舞蹈姿势表】，使用参考图中的角色，在【正方形】画面里放置恰好【16】个大小完全一致的分格，背景【纯白】。

角色一致性：在全部分格中，必须保持以下特征一致：【脸部/发型/配色/身体比例/服装/配饰/原本的美术风格】。不要重新设计角色。
如参考图中某些细节看不清，请保守补全，并确保这些补全在全部格子里保持一致。

分格内容：按【从左到右、从上到下】的顺序，依次为【逐格列出】……
```
> 要点：**行列数写死、每格内容逐条写、加一致性条款**——三件事缺一就会出现"格子数不对/角色每格长得不一样"。

### 模板 H · 海报文字排版
```
【比例】海报，【底色/背景构成】。
主体：【人物/产品 + 姿态 + 位置】。
文字（逐字给出）：
- 左上角小号：【英文/中文文案】
- 画面主标题（超大、加粗、窄体、全大写）：【文案】
- 底部小字：【文案】
排版：【谁大谁小、颜色、是否手写体/印刷体】。
配色：【主色 + 辅色】。
限制：不包含任何文字（除上述 N 处）、标志、水印、边框。
```

## 5. 五个实战改写演示

### 演示 1：`画一个动漫女孩` → Niji 7 立绘
**改写后**
```
official anime key visual, 1 girl, 16 years old, silver-white short bob hair with fluffy bangs,
large sparkling blue eyes, fair skin with soft blush, calm melancholic expression,
navy sailor school uniform with white shirt and red ribbon, single shoulder bag,
standing on stone steps, paused mid-step, looking back over her shoulder,
medium shot, eye-level camera, centered composition, white background,
soft rim light from the sunset, clean lineart, cel shading, gentle gradient,
vibrant but soft colors
--niji 7 --stylize 250 --no text, watermark, blur, bad hands
```
**为什么这么改**：加了身份年龄、4 项外貌、服装分件、定格动作、机位景别、白底、光线收尾；参数只留必要的。

### 演示 2：`做个好看的海报` → GPT Image 2.5 规格书
**改写后**（节选自站上真实案例的骨架）
```
目的：为青春恋爱题材动画电影制作一张竖版海报。
画布：竖版 9:16，柔和景深、夕阳轮廓光、粉色与金色的色调组合。
主体：半身出镜的女高中生，越过肩膀回头望向镜头，银白色短波波头，宁静略带忧郁。
背景：通往海边小镇的陡峭石阶，两侧樱花树，花瓣飘舞，远处海湾与低垂暖阳。
文本内容：底部中央醒目的手写风格白色标题：“在那坡道上，樱花盛开时”。
视觉风格：高品质现代日本动画电影海报风格，细腻的花瓣，电影级调色。
限制要求：画面仅包含一名主要角色、一个书包、一条红丝带；严禁额外角色、Logo、水印。
```
**为什么这么改**：把"好看"翻译成了可执行的**画布 / 主体 / 背景 / 文字 / 风格 / 限制**六件套。

### 演示 3：`帮我把这张照片改成动漫风` → Banana 编辑指令
**改写后**
```
参考图1的人物，保持五官、发型与服装完全一致，不要修改角色设计。
将整张照片转绘为日系动画电影截图风格：赛璐璐平涂 + 柔和渐变线稿。
背景保持构图不变，改为虚化的黄昏街道，加入暖橙色轮廓光与轻微光晕。
在左上角添加逐字文字：“2026 春”。
```
**为什么这么改**：编辑类必须先锁身份，否则模型会把脸也重画；要加的字逐字给出。

### 演示 4：`画一只猫` → Niji 7 氛围场景
**改写后**（思路来自站上高赞案例：用"物件 + 状态"叙事）
```
A lonely, worn-out black cat plush sitting on top of an old clothing donation box in a quiet Japanese neighborhood.
The stuffed toy has faded black fur, loose seams, dusty fabric, floppy ears, and a small stitched smile.
Empty residential street, telephone poles, weeds growing through cracked pavement, gentle breeze moving fallen leaves.
Soft evening light, bittersweet nostalgia, shallow depth of field, realistic textures
--sref 【风格码】 --niji 7 --raw
```
**为什么这么改**：把"一只猫"变成"一只被丢弃的旧玩偶坐在旧捐衣箱上"——**情绪来自状态与关系，不来自形容词**。

### 演示 5：`做成三视图` → 用模板 G
**改写后**
```
参考图片角色，制作她的三视图，正面，侧面，背面，视图平行排开，画幅16:9。
背景纯白，不包含任何边框、水印或文字标签。三个视图大小一致、间距均匀。
保持角色的发型、服装、配饰、配色完全一致。
```
**为什么这么改**：补上了"白底 + 等大 + 平行排开 + 一致性"四项交付规格——这正是站上 [3] 那条三视图案例虽然极简、却能稳定出图的原因。

**语法三条铁律**（来自全库反例统计）：
1. 相邻词之间**必须有分隔符**（逗号或空格），中英/中日混排尤其注意。
2. 一条参数或比例**只写一次**。
3. 画面上出现的文字**逐字给出**，不要写"加一句励志文案"。

## 7. 参数速查卡（Niji 7）

| 参数 | 范围 | 怎么用 |
| --- | --- | --- |
| `--niji 7` | — | 必带；166 条里 155 条带它，其中 **90 条只带它一个** |
| `--stylize` / `--s` | 0–1000 | 0–200 收敛忠实；**200–600 最佳**；800+ 装饰过度、轮廓失准；新手 200 |
| `--chaos` / `--c` | 0–100 | 0–10 四张高度一致；50+ 差异大；常用 15–30 |
| `--raw` | — | 关自动美颜，严格遵循提示词；做线稿/三视图/设定稿时开 |
| `--no` | — | 常带 `--no text, watermark, blur, bad hands`；纯线稿 `--no shading`；白底 `--no background` |
| `--sref` | 风格码 | 写法 `--sref 3397777607`；多码用空格分隔（2–3 个为宜，比例固定 50/50） |
| `--sw` | 0–1000 | 风格强度：100–300 轻量；**500–700 最实用**；800–1000 强锁（此时提示词只管主体构图） |
| `--weird` / `--w` | 0–3000 | 少量尝试，常用 4 |
| `--ar` | — | **Niji 7 用不上**，全库 0 条使用 |

> `--style raw` 两个坑：写成 `--styleraw` 不生效；每个后缀前后都要有空格。

## 8. 排错表：症状 → 原因 → 改法

| 症状 | 多半是什么原因 | 怎么改 |
| --- | --- | --- |
| 主体不像 | 外貌只写了"可爱" | 补 3–5 项可画特征（发色发型/瞳色/肤色/表情/服装分件） |
| 画面平、像素材图 | 缺光线描述 | 加"主光源方向 + 阴影边缘 + 色彩对比"三件套 |
| 没有视觉重点 | 缺景别与景深 | 加 `close-up`/`半身`、`浅景深`、`背景虚化` |
| 画面太满太乱 | 没给留白指令 | 加 `大面积留白`/`纯色背景`/`简化背景` |
| 画风不对味 | 风格词只给了"动漫" | 换成工艺级词（赛璐璐平涂 / 厚涂 / 水彩 / 线稿）或直接引导演/游戏风格 |
| 文字全是乱码 | 没给逐字内容 | 逐字写出文案 + 位置 + 字体风格 |
| 角色每格长得不一样 | 多格没写一致性条款 | 加"全部格子保持脸部/发型/配色/服装一致"并规定看不清处保守补全 |
| 参考图把画风也带过去了 | 没显式解绑 | 加"禁止维持参考图画风/姿势，参考图只提供长相" |
| 改图时连不该改的也改了 | 没写"保持" | 显式列出"保持 X、Y、Z 不变" |
| 人物比例/大小失控 | 没标尺度 | 写"身形仅占画面约 2.5%"这类明确百分比 |
| 想出透明底却给了白底 | 写成了条件句 | 改成硬性要求"必须输出透明背景" |
| 一样的人越画越不像 | 每张都重写描述 | Niji 7 用同一组 `--sref` + 括号内固定外形描述；其他模型用同一张参考图 |
| 词写了没反应 | 被后面的词淹没或冲突 | 精简到 1–3 个质量词；删掉互斥风格；把关键约束放前面或单独成行 |
| 中英混排效果怪 | 词粘在一起 | 补分隔符/空格 |

## 9. 出图前自检清单

1. 交付物（用途 + 比例）写了吗？
2. 主体有没有 3 项以上**可画**特征？
3. 风格词是工艺级（平涂/厚涂/水彩/线稿/3D 渲染）而不是"好看"？
4. 镜头（景别 + 机位 + 构图法）写了吗？
5. 光线有方向 + 有性质（硬/柔/逆光）吗？
6. 色彩写了色调 + 饱和度吗？
7. 材质写了至少一处吗？
8. 质量词是否 ≤3 个？
9. 所有相邻词都有分隔符吗？
10. 比例只出现一次吗？
11. 画面文字是否逐字给出（含位置与字体）？
12. 限制条件（不要什么）写了吗？
13. 用参考图时，"保持什么/改变什么"是否分开写清？
14. 多格图是否写了一致性条款 + 每格内容？
15. 需要"小主体"时有没有标百分比？
16. 风格词之间是否互相冲突？
17. Niji 7 是否只带了必要参数（`--niji 7` ± `--stylize`/`--raw`/`--sref`）？
18. 有没有误写 `--styleraw`、`--ar`？
19. 是否只改了一处就重新出图？
20. 出片成功后，有没有把提示词存成带 `【】` 变量的模板？

## 10. 练习（做完就基本掌握了）

**练习 1 · 立绘**：用模板 A 写一个"雨天撑透明伞的少年"立绘。要点：白底、全身、服装分件、`--stylize 200`。
**练习 2 · 氛围场景**：用"物件 + 状态"叙事写一只"被遗忘在自动贩卖机旁的旧玩具"。要点：光线与情绪，不写"孤独"两个字，让画面自己说。
**练习 3 · 海报**：用模板 D 写一张"独立音乐节海报"。要点：比例、主标题逐字、排版层级、限制条件。
**练习 4 · 改图**：给一张自己的照片，写一条 Banana 指令：只换背景为"深夜便利店门口"，人物与服装完全不变，并加一行逐字文字。
**练习 5 · 设定图**：用模板 G 做一张 4 格表情表（元气/冷脸/害羞/嫌弃），必须写一致性条款。

**进阶练习**：去 `krene.com/prompt` 找三条你喜欢的提示词，用本文的槽位表逐条标注它们**分别写了哪些槽位、漏了哪些**——你会发现自己能"看懂"提示词了，这是最快的学习方式。
